Canvas2D page-turn prototypes

Three synchronized 2D implementations. Each uses the same interpolated page silhouette. The underlying book remains static; only the turning leaf is animated.

Ready

1. Outline only

A moving leaf contour with no interior fill. Shows the geometry without hiding the underlying page.

2. Stationary tiled texture

Same silhouette, clipped to a repeating parchment texture. Texture does not rotate, stretch, or warp.

3. Texture + simulated fold

Adds a narrow moving fold, light rim, and soft cast shadow to suggest a lifted sheet.

Try Next and Previous. Replay repeats the last direction. This is a single standalone file: no images, libraries, or network requests. All artwork is drawn with Canvas2D.
